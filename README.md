# 🌱 Grădina Mea – organizator de grădinărit

Aplicație web gratuită, instalabilă pe telefon și pe calculator (PWA), care îți face calendarul grădinii în funcție de **locație** și **vreme**.

**👉 Deschide aplicația: https://bm2011.github.io/gradina-mea/**

## Ce face
- Legume, aromatice, viță de vie, pomi, arbuști fructiferi și flori; poți adăuga și plante proprii.
- Locația se ia automat sau se caută după localitate, oriunde pe glob. Datele de îngheț se calculează din istoricul meteo al ultimilor 3 ani.
- Sarcinile acoperă tot ciclul: semănat, plantare, îngrijire, tratamente, tăieri, recoltare, semințe și butași.
- Ține cont unde e plantată cultura: câmp, tunel, solar, seră sau ghiveci.
- Reacționează zilnic la vreme, pe baza prognozei pe 16 zile: mută lucrările și dă alerte de îngheț, caniculă, boli și vânt.
- Fiecare sarcină are instrucțiuni pas cu pas, ilustrații și unelte, cu trei variante: Bio, Convențional sau Gratuit.
- Ține cont de sarcinile nerealizate și trimite alerte.

## Instalare
- **Android / Chrome / Edge:** deschide linkul → meniul browserului → „Instalează aplicația”.
- **iPhone / iPad:** în Safari → Distribuie → „Adaugă pe ecranul principal”.

Datele se păstrează local, pe fiecare dispozitiv. Le poți muta de pe un dispozitiv pe altul din Setări → Exportă / Importă.

Date meteo: [Open-Meteo](https://open-meteo.com) (CC BY 4.0).
